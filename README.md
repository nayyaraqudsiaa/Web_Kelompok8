Deskripsi Aplikasi Rekos (Recycle Kos)
platform yang dirancang untuk memfasilitasi jual beli barang kos bekas yang masih layak pakai, 
dengan tujuan membantu mahasiswa memperoleh kebutuhan kos dengan harga terjangkau serta mengurangi limbah barang yang masih dapat digunakan.
